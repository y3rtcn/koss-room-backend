# 백엔드 A API 안내

## 공통 규칙

- 로컬 주소: `http://localhost:8000`
- API 주소 끝의 `/`를 포함한다.
- 기능 API는 Google 로그인 후 Django 세션 쿠키로 인증한다.
- JSON 본문을 보내는 요청은 `Content-Type: application/json`을 사용한다.
- POST·PUT·PATCH 요청은 세션 쿠키와 `X-CSRFToken`이 필요하다.
- `GET /api/csrf/`에서 CSRF 토큰을 받는다. 로그인 후 토큰을 다시 받는다.
- 날짜·시간 입력에는 시간대를 포함한다. 예: `2026-11-10T14:00:00+09:00`
- 응답 시간은 입력과 다른 시간대 오프셋으로 표시될 수 있다.

## 인증·회원 정보

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/accounts/google/login/` | Google 로그인 확인 화면 |
| POST | `/accounts/google/login/` | Google 인증 시작 |
| GET | `/accounts/google/login/callback/` | Google 인증 결과 수신 |
| GET | `/accounts/logout/` | 로그아웃 확인 화면 |
| POST | `/accounts/logout/` | 로그아웃 실행 |
| GET | `/api/accounts/me/` | 본인의 ID·이메일·닉네임 조회 |
| PATCH | `/api/accounts/me/` | 본인 닉네임 설정·수정. 요청 예시 `{"nickname": "스터디원"}` |

국민대 Google 계정만 허용하며 첫 로그인 시 사용자를 자동 생성한다. 별도 회원가입 화면은 사용하지 않는다. 현재 로그인 성공 후 `/api/attendance/me/`로 이동한다.

학교 계정 인증과 동아리원 자격 확인은 별개다. 현재 별도의 동아리원 승인·허용 목록은 구현하지 않았다.
- 닉네임은 앞뒤 공백을 제거한 뒤 1~30자이며 줄바꿈과 제어 문자는 허용하지 않는다. 첫 로그인 시 닉네임이 비어 있으면 프론트에서 입력을 안내한다.

## 공간

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/spaces/` | 사용 가능한 공간 목록 |
| POST | `/api/spaces/create/` | 관리자 공간 추가 |
| PATCH | `/api/spaces/{id}/` | 관리자 정원 수정 |

관리자는 사용자 모델의 `is_staff=True`인 계정이다.

추가 요청 예시:

```json
{"name": "테이블 A", "capacity": 4}
```

정원 수정 요청 예시:

```json
{"capacity": 6}
```

공간 이름은 공백 제거 후 1~50자이며 중복을 허용하지 않는다. 추가·수정 API의 정원 허용 범위는 1~32767이다.
- 진행 중이거나 예정된 일정의 모집 정원 또는 참여 인원보다 공간 정원을 낮추면 `409 space_capacity_conflict`를 반환한다. 종료·취소된 일정은 검사에서 제외한다.

## 일정

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/schedules/` | 취소되지 않은 일정 목록 |
| POST | `/api/schedules/create/` | 일정 등록 |
| GET | `/api/schedules/{id}/` | 상세 조회, 취소 일정 포함 |
| PUT | `/api/schedules/{id}/update/` | 작성자만 수정 |
| POST | `/api/schedules/{id}/cancel/` | 작성자만 취소 |

등록·수정 요청 예시:

```json
{
  "title": "파이썬 스터디",
  "space_id": 1,
  "starts_at": "2026-11-10T14:00:00+09:00",
  "ends_at": "2026-11-10T15:00:00+09:00",
  "expected_count": 4,
  "purpose": "공부",
  "confirm_overlap": false
}
```

- `space_id`는 실제 공간 목록에서 받은 ID를 사용한다.
- PUT 수정도 위의 일정 필드를 모두 보낸다. `confirm_overlap`은 생략 가능하며 기본값은 false다.
- 작성자는 서버가 로그인 사용자로 지정한다.
- 종료 시간은 시작 시간보다 뒤여야 한다.
- 제목·목적·공간 이름은 한글과 일반 문장부호를 허용하며 줄바꿈과 제어 문자는 거절한다.
- 예상 인원은 모집 정원으로도 사용하며 공간 정원을 넘을 수 없다.
- 정원을 현재 참여 인원보다 작게 수정할 수 없다.
- 취소된 일정은 수정할 수 없다.
- 현재 목록 조회에는 날짜 필터와 페이지 구분이 없다.

### 시간 충돌

같은 공간에서 취소되지 않은 일정과 시간이 겹치면 HTTP 409와 다음 정보를 반환한다.

```json
{
  "error": {
    "code": "schedule_overlap",
    "message": "같은 공간에 겹치는 일정이 있습니다. 확인 후 다시 요청하세요."
  },
  "conflicts": [
    {
      "id": 2,
      "title": "기존 일정",
      "starts_at": "2026-11-10T14:00:00+09:00",
      "ends_at": "2026-11-10T15:00:00+09:00"
    }
  ]
}
```

사용자가 확인하면 동일한 요청에 `confirm_overlap: true`를 넣어 다시 보낸다. 재요청 시점의 겹침을 허용하고 저장한다.

앞 일정 종료와 다음 일정 시작이 같은 경우는 충돌이 아니다.

## 참여

| 메서드 | 경로 | 설명 |
|---|---|---|
| POST | `/api/schedules/{id}/join/` | 본인 참여 신청 |
| POST | `/api/schedules/{id}/leave/` | 본인 참여 취소 |
| GET | `/api/schedules/{id}/participants/` | 참여자 목록 |

- 작성자는 일정 생성 시 자동 참여하며 모집 정원에 포함된다.
- 정원 4명은 작성자 1명과 추가 신청자 최대 3명을 뜻한다.
- 반복 신청·반복 참여 취소는 중복 변경 없이 `changed: false`를 반환한다.
- 작성자는 개별 참여 취소가 불가능하며 일정 취소를 이용한다.
- 취소된 일정에는 참여 신청·참여 취소가 불가능하다. 기존 참여 기록은 유지한다.
- 종료된 일정에 신규 참여를 신청하면 `409 schedule_ended`를 반환한다.
- 참여자 목록에는 사용자 ID·닉네임·작성자 여부를 반환하며 이메일은 제외한다.
- 요청 본문으로 다른 사용자를 지정할 수 없다.

## 오류·알림

일반적인 오류 형식:

```json
{
  "error": {
    "code": "authentication_required",
    "message": "로그인이 필요합니다."
  }
}
```

주요 상태 코드: 비로그인 401, 권한·CSRF 오류 403, 대상 없음 404, 입력 오류 400, 시간 충돌·정원 초과 등 상태 충돌 409.

일정 등록 성공은 201, 수정·취소·참여 처리는 200을 반환한다.

일정 등록·수정·취소·참여 변경 시 B의 `schedule.changed` 알림을 연결한다. 알림은 DB 커밋 후 전송하며 프론트는 관련 API를 다시 조회한다. 연결 복구 시에도 다시 조회한다.

## 검증 현황

- PostgreSQL 전체 테스트 98개 통과. 마지막 자리 동시 신청과 같은 공간·시간 동시 등록 검증 포함.
- 프론트 실제 연동·배포 검증은 남아 있다.
